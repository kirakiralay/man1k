# Telegram bot reminder (manicure) - aiogram 3

Бот позволяет создать запись о маникюре:
стиль ногтей → дата (календарь на месяц вперёд) → время (10:00–23:00 каждый час) → подтверждение.

После подтверждения:
1) запись добавляется в Google Sheets (колонки: `Стиль ногтей`, `Дата`, `Время`);
2) пользователю отправляется файл `.ics`, который нужно открыть и импортировать в системный календарь на устройстве.

## Установка

1. Установите зависимости:
   - `pip install -r requirements.txt`
2. Создайте файл `.env` (или задайте переменные окружения в Railway).

## Настройка Google Sheets

1. Создайте Google Sheet.
2. Создайте сервисный аккаунт в Google Cloud.
3. Вставьте JSON ключ сервисного аккаунта как строку в переменную `GOOGLE_SERVICE_ACCOUNT_JSON`.
4. Откройте Google Sheet и предоставьте доступ сервисному аккаунту (email из `client_email` ключа).
5. Укажите `GOOGLE_SPREADSHEET_ID` и (опционально) `GOOGLE_WORKSHEET_NAME`.

Колонки будут добавлены автоматически, если в первой строке листа пусто.

## Запуск

- `python main.py`

## Команды в Telegram

- `/start` — приветствие
- `/new` или кнопка `Создать запись` — создать запись
- `/cancel` — отменить текущий процесс
